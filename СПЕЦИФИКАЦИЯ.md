# Спецификация
**Проект для яндекс лицея.** 
Своей целью я выбрал создать программу для анализа использования диска в `Linux/Windows` (Референс: [KDE Filelight](https://apps.kde.org/filelight/)). 

До этого я работал с C и Rust, хотелось бы на них проект и писать но увы.

Технологии: 
 - **Хранение прошлых снапшотов**: `sqlite3` (lib)
 - **Графика**: `PyQt6`
 - **Бэкенд (сам сканнер диска)**: `Cython` - обычный Python был бы слишком медлитилен (скомпилируется в `.so/.dll`)
